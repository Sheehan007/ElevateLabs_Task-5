# ElevateLabs_Task-5
Extracted the Titanic dataset (≈ 891 rows × 12 columns) from Kaggle and performed Exploratory Data Analysis (EDA) on the dataset to discover patterns, spot anomalies, test basic assumptions, and generate hypotheses for modeling. 

Using Seaborn made meaninful plots such as Countplot, Violinplot and Boxplot revealing interesting patterns between the chances of Survival and Age and Fare. 

Made a Correlation Matrix which showed that Fair was the factor that led to the most survival chances of the people onboard the Titanic. 

Finally, delivered a PDF report stating all the observations.
